# Workbench

Workbench自身の開発・保守・改善を管理するProject。

## Scope

- Workbenchの機能追加・不具合修正
- Obsidian設定、Dashboard、Bases、FileClassesの改善
- Workbenchローカルプラグインの開発
- 外部Obsidianプラグインの追加・削除・更新
- README、AGENTS、ONBOARDINGなどのドキュメント整備
- Workbenchの設計・運用改善

## Task management

Workbench自身に対するTaskは、このProjectに紐づけて管理する。

```yaml
projects:
  - "[[Workbench]]"
```

別プロジェクトを対象とするTaskは、その対象Projectに紐づける。
