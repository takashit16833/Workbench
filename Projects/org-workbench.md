# org-workbench

CLI Emacs 上に Org 版 Workbench を作るための、一時的な開発 Project。完成後は新しい Workbench に移行する。

## 初回マイルストーン

RAGScope と Workbench のタスクを Org に登録し、作成・状態変更・Project 別 Agenda・日々の進捗確認ができること。

タスクは `Tasks/Org Workbench 01 ...` から `08 ...` の順に進める。各 Task の「完了条件」を満たしたら完了にする。

設計の正本: [Org Workbench design.org](https://github.com/takashit16833/.emacs.d-cli/blob/feat/org-workbench/workbench/design.org)
実装先: [Emacs 設定の feat/org-workbench](https://github.com/takashit16833/.emacs.d-cli/tree/feat/org-workbench)

## 初回リリース後

Project 削除、Clear、Pomodoro、休日・予定の一括変更、アイデア・ノート管理などは初回の完成条件にしない。リリース後、新しい Workbench 内の Workbench Project に改善タスクとして登録する。
