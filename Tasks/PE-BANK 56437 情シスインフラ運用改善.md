# 情シス部門インフラ運用・改善支援

## 概要

案件番号: 56437-38

社内SE・情報システム部門で、Windows Server / Active Directory / DNS / DHCP、サーバ監視、ネットワーク運用、ベンダー連携、運用改善を担当する常駐案件。リーダーまたはメンバーを募集。

## 主な業務

- ヘルプデスクからのエスカレーション対応
- アカウント・権限管理
- Active Directory、DNS、DHCP、Windows Server運用
- サーバ監視、障害調査、一次切り分け
- ベンダー連携
- LAN / WAN、拠点ネットワーク、閉域網運用
- ネットワーク設定変更、チューニング
- 運用手順書、各種ドキュメント整備
- 運用改善、業務フロー改善

## 開発環境

- Windows Server
- Active Directory
- DNS
- DHCP
- LAN / WAN
- サーバ監視

## 必須経験

### リーダー

- 情報システム部門または社内SEでのインフラ運用4年以上
- インフラ運用リーダーまたは顧客・ベンダー調整
- 運用改善提案、業務フロー構築
- Windows Server / Active Directory / DNS / DHCP
- サーバ監視、障害対応、ネットワーク運用

### メンバー

- 情報システム部門、社内SE、ヘルプデスク二次対応1〜2年以上
- Windows Server / Active Directory
- サーバ監視、障害一次切り分け
- LAN / WANの基本知識
- ドキュメント作成
