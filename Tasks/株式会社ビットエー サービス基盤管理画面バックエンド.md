# サービス基盤管理画面のバックエンド開発案件【Python】

## 概要
インターネット基盤サービスのバックエンド機能開発案件。マイクロサービスアーキテクチャを採用し、PythonによるAPI設計・実装・テスト・リリースを担当する。

## 主な業務
- APIおよびデータベースの設計・実装・テスト・リリース

## 必須経験
- Python 3.9以上での開発実務経験2年以上
