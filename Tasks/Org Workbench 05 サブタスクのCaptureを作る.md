# タスク作成から親を指定して子タスクを追加する

## 完成イメージ

タスク04で用意する「Workbench: タスク作成」をそのまま使い、既存タスクや整理用見出しを親に指定すると、**その親の直下に子タスクを追加できる**ようにする。子タスク専用の Capture テンプレートは作らない。親を指定しなければ新しいファイルに親タスクを作り、親を指定した場合だけ既存ファイルに見出しを追加する。

親の Org ファイルを手作業で探す必要はなく、親が子タスクでもさらにその下に孫タスクを作れる。階層の深さは制限しない。

### 操作例：RAGScope のタスクを細分化する

1. 「Workbench: タスク作成」から、子タスクを追加する操作として既存の親を検索・指定する。
2. 「API の性能を改善する」を親に選ぶ。検索結果で対象のファイル・見出しを区別できるようにする。
3. タイトル「SQL の実行計画を調べる」を入力する。Project は任意で、未選択なら親の所属を継承する。日時や本文などは Capture 中または保存後に Org の見出しを編集する。
4. `C-c C-c` で確定すると、選んだ親の直下に見出しが追加される。`C-u C-c C-c` なら保存後に作成した子タスクへ移動できる。

例えば元のファイルが次の状態だった場合、

```org
* TODO API の性能を改善する :p_ragscope:
:PROPERTIES:
:ID:       parent-id
:END:

性能改善の方針を整理する。

** TODO API の計測を行う
```

「SQL の実行計画を調べる」を追加したあとのイメージは次のとおり。

```org
* TODO API の性能を改善する :p_ragscope:
:PROPERTIES:
:ID:       parent-id
:END:

性能改善の方針を整理する。

** TODO API の計測を行う

** TODO SQL の実行計画を調べる
:PROPERTIES:
:ID:       child-id
:CREATED:  [2026-09-22 Tue 11:00]
:END:

実行時間とボトルネックを確認する。
```

※ ID・日時・本文は説明用の例。子タスクは親の `:p_ragscope:` をタグ継承で受け取るため、同じタグを子の見出しに重複記述しない。子の Project を追加で Workbench にも所属させたい場合は、子の見出しに `:p_workbench:` を付ける。親の所属を解除する専用機能は今回作らない。

### 操作例：雑用ファイルに小さなタスクを追加する

TODO のない「雑用」という整理用見出しも親に選べる。例えば `雑用.org` が次のようになっている場合、

```org
* 雑用
```

同じ「タスク作成」で「雑用」を親に選び、「牛乳を買う」を登録すると、次の形になる。

```org
* 雑用

** TODO 牛乳を買う
:PROPERTIES:
:ID:       child-id
:CREATED:  [2026-09-22 Tue 11:00]
:END:
```

牛乳用の独立ファイルは作らない。一方、親を選ばず「牛乳を買う」を作成すれば、無所属の親タスクとして別ファイルに保存できる。タスクの大きさによって作成方法を強制しない。

### 保存・キャンセル時の扱い

既存の親見出しのタイトル・本文・ID、すでにある兄弟タスクを保持し、選んだ親の下に新しい見出しだけを追加する。子・孫それぞれの ID は異なる。キャンセル時には子見出しを残さず、再起動後も階層を保持する。

**このタスクではタスク04の共通の作成入口に、親を指定する経路を追加する。** Project 別・親別の一覧表示はタスク06で扱う。上記は完成予定の操作例であり、現時点で実装済みという意味ではない。

## やること

既存タスクを検索して親に指定し、その直下に新しい見出しを追加する。作成メニューは増やさず、親を選ばない場合はタスク04の独立ファイル作成を利用する。

- ID またはファイル位置から既存タスクを補完検索し、任意の深さの見出しを親に選べるようにする。
- 入力はタイトル（必須）と Project（任意）を基本とし、親の指定は子タスクを追加するときの操作で扱う。TODO・ID・CREATED を自動設定する。
- 子は親の所属 Project を継承し、必要なら別 Project を追加できる。親の見出し・本文・兄弟タスク・ID を壊さない。
- 雑用のような TODO なしの整理用見出しも追加先にできる。日時・優先度・本文などは Capture 中または保存後の Org 編集で設定する。
- 通常保存と保存後の移動に対応し、キャンセルした子見出しを残さない。

## 完了条件

- 「Workbench: タスク作成」の同じ入口から、RAGScope タスクの子と孫を作れる。別の Capture テンプレートは不要。
- 雑用ファイルの配下に「牛乳を買う」を追加でき、牛乳用の独立ファイルはできない。親を選ばなければ独立ファイルにも作成できる。
- 親の所属が継承され、子に別 Project を追加できる。親・兄弟を壊さず、親子の ID が重複しない。
- 保存・キャンセル・再起動後も正しい位置と階層を保ち、保存後すぐに子タスクを開いて編集できる。
