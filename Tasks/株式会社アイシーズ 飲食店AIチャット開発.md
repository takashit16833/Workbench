# 飲食店AIチャット開発

## 概要

飲食チェーン向けの店舗自己解決ツール（AIチャット／検索）の開発案件。GCPの会話型AIを使った回答生成・検索精度改善を中心に、UI改善、音声AIの試作、外部SaaS連携、文書・問い合わせ履歴のテキスト抽出、FAQデータ整理まで担当する。

## 主な業務

- 店舗向けAIチャット／検索機能の開発
- GCP Conversational Agents等を使った回答生成・検索精度改善
- カテゴリ選択、サイドバー、音声入力などのUI/UX改善
- STT/TTSを使ったボイスボットの検証・プロトタイプ開発
- Teachme Biz等の外部SaaSとのAPI連携
- Excel、PDF、問い合わせ履歴のテキスト抽出・プロンプト最適化
- FAQデータ構造の整理と問い合わせ窓口統合に向けた連携開発

## 開発環境

- Python
- TypeScript
- React
- AWS / GCP
- Docker

## 必須経験
