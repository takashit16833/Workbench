# Databricks移行・生成AI活用開発【Python / SQL】

## 概要

既存のApache SparkデータパイプラインをDatabricksへ移行する案件。各システムから収集した契約者データ等を基に、シルバー層・ゴールド層のデータを作成する処理を移行する。Claude等の生成AIを開発作業に積極的に利用する方針。

**生成AIサービスそのものを開発する案件ではなく、AIを開発支援に用いるデータ処理基盤の移行案件。**

案件紹介元: 株式会社メソドロジック（PE-BANK 山田氏経由）

## 主な業務

- 既存Apache Sparkデータパイプラインの調査・理解
- Databricksへの既存処理の移行
- 契約者データ等を元にしたシルバー層・ゴールド層向けのデータ加工処理
- Python / SQLによる開発
- Claude等を使った開発効率化、生成コードの読解・検証・修正

## 開発環境

- 言語: Python、SQL
- クラウド: AWS
- 移行先: Databricks
- 移行元: Apache Sparkのデータパイプライン
- ソースコード管理: Git
- 自動化: CI/CDツール（製品の指定なし）
- AI開発支援: Claude等

## 必須経験
