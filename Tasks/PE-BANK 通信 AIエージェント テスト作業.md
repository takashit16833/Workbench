# 通信 AIエージェント テスト作業

## 概要

通信系AIエージェント案件のテスト作業。
主な作業は画面の打鍵テストと、ツールを使用したAPIテスト。
AIエージェント案件ではあるが、募集内容上はAI機能の設計・開発ではなくテスト業務が中心。

## 主な業務

- 画面の打鍵テスト
- ツールを使用したAPIテスト
- 関係者との報告・連絡・相談
- 案件状況に応じた出社対応

## 開発環境

- Javaバックエンド
- Web API
- Webアプリケーション
- 大規模アジャイル / スクラム（歓迎要件）

## 必須経験

- 多方面の関係者とコミュニケーションが取れ、報告・連絡・相談を問題なく行えること
- Javaバックエンドの開発経験
- APIの知見、または外部接続に関する知見

## 歓迎経験

- 開発者としてWebアプリケーション開発の一連の工程を経験
- 大規模アジャイル開発への参画経験
- スクラム開発の実務経験1年以上

## 条件

- 開始: 2026年10月中旬〜
- 勤務形態: 原則フルテレワーク
- 案件状況により出社の可能性あり
- 出社先候補: 豊洲、春日
- 勤務時間: 9:30〜18:30
- 募集人数: 7名
- 面談: 2回
- 外国籍不可
- 単価: 時給制（月額単価÷160時間）
- 3年程度: 月額55〜60万円
- 5年程度: 月額60〜65万円
- レビューやリーダー対応可能な7年以上のSE: 月額75万円〜、応相談

**強く合う:** API知識、Webアプリの一連工程、バックエンド全般の経験。テスト自体にも十分対応できる。

**注意:** 必須の「Javaバックエンド開発」が完全一致ではない。Java実務はあるが、Web API系のJavaバックエンドとしては弱い。また、本人は基本的にバックエンド開発や上流工程を志向しており、本案件は画面打鍵・APIテスト中心のため今後の方向性との一致は弱い。

**単価面:** 通常SE枠の月額55〜65万円は、PE-BANK向けに現在設定している税込71万円程度の最低ラインを下回る。75万円〜のリーダー枠は条件詳細が不明で、リーダー前提での応募を強く勧める根拠はない。

**応募判断:** 10月中旬開始・原則フルリモートは魅力だが、仕事内容・Java要件・単価を合わせると優先度は低い。現場復帰を最優先して条件をさらに緩める場合の候補。
