# 証券システム部門の社員代替支援

## 概要

案件番号: 56255-65

某オンライン証券会社の情報システム部門で、社員代替として要件定義から本番リリースまでの案件管理・推進を担当する。

## 主な業務

- 業務要件のヒアリング、システム要件定義
- システム要件定義書、プロジェクト計画書の作成
- ベンダーコントロール
- 進捗、課題、品質、コスト管理
- 品質管理部門への報告
- 要件定義から本番リリースまでの案件管理・推進

## 開発環境

- Linux
- SQL
- Word / Excel / PowerPoint

## 必須経験

- ドキュメント作成スキル
- バッチシステムの設計・開発経験5年以上
- Linuxの基本知識
- SQLの知識

## 歓迎経験

- 証券業界プロジェクト参画経験
- 証券取引の知識・経験
- PMO、プロジェクト推進経験
- ベンダーコントロール経験

## 条件

- 期間: 即日〜長期
- 勤務地: 東京23区
- 最寄り: 全国
- 勤務形態: 基本リモート
- 契約金額: 900,000円、スキル見合い

## マッチ度評価

総合: D（相性が低い）

- ◎ ドキュメント作成: 要件整理・設計書作成を含む上流工程の実務経験がある。
- × バッチシステム設計・開発5年以上: 経歴書から5年以上のバッチシステム経験を確認できない。
- ? Linux基本知識: 実務での明確な記載が経歴書上では弱い。
- ◎ SQL: MySQL / PostgreSQL等を用いた実務経験があり、SQL性能改善の経験もある。
- × 証券業界・証券取引: 経歴書から確認できない。
- △ PMO・プロジェクト推進: 要件整理や仕様調整、リーダー経験はあるが、社員代替PMOとしての進捗・品質・コスト管理を主担当した実績は確認できない。
