# ADR-0003に合わせてJSON契約とstderr出力を切り替える

ADR-0003で採用したログモデルの型構造に対応するJSONへ、Schema、fixture、productionのstderr出力を一括して切り替える。

このTaskで旧root平坦化JSONから`spec`を持つ新しいJSON契約への移行を完了させる。

## やること

- `log-event.schema.json`をADR-0003に合わせて更新する
- rootの共通項目と`EventSpec`由来の項目を分離する
- JSONに`spec` objectを追加する
- 以下を`spec`配下へ移す
  - `operation`
  - `event`
  - `level`
  - `payload`
  - `error`
- `event = failed`の場合の
  - `level = error`
  - `error`必須
  のSchema条件を新しい`spec`構造へ合わせる
- `EventContext`のSchemaをAeson表現と整合させる
- Timestampの制約をTask 1で確定したAeson表現と整合させる
- valid fixtureを新構造へ更新する
- invalid fixtureを新構造へ更新する
- `AesonStderr`を完成済み`ToJSON LogEvent`へ接続する
- production出力を`encode logEvent`中心の実装へ変更する
- JSON表現を重複実装している旧`encode*`関数を削減する
- `AesonStderr`をstderrへの1行出力とIO失敗処理を中心とした薄いBackendにする

## 完了条件

- JSON SchemaがADR-0003の`spec`構造を表現している
- valid / invalid fixtureが新しいSchema構造へ更新されている
- productionのstderr出力が`Backend.Aeson`の`ToJSON`を使用している
- `AesonStderr`にJSON構造を手作業で組み立てる責務が残っていない
- 1つのLogEventがstderrへ1行のJSONとして出力される
