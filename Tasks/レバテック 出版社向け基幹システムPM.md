# 出版社向け基幹システムPM

## 概要
出版社向け基幹システム開発で、3チームの進捗・リソース管理、要件定義、顧客折衝、技術品質管理、テスト管理を担うPM案件。

## 主な業務
- 3チームの全体進捗管理、リソース調整
- 要件定義、エンドクライアントとの折衝
- コードレビューを含む技術品質管理
- テストシナリオ策定、管理

## 開発環境
- PHP / Go / TypeScript / SQL
- React / Gin
- PostgreSQL / Aurora
- AWS
- Terraform / Docker / Node.js
- Git / GitHub

## 必須経験
- PMまたはチームマネジメント経験
- Webアプリケーションのフルスタック経験
- PHPまたはGoの開発・レビュー経験
- SQLパフォーマンスチューニング
- Gitによるチーム開発
- AWSの知見・構築経験

## 歓迎経験
- TypeScript / React
- TerraformによるIaC

## マッチ度評価
**総合: C（条件付き）**

- △ PM / チームマネジメント: 大規模なPM経験はない。初期キャリアで小規模なBtoC Webアプリ開発をPJリーダーとして担当した経験はあるが、3チーム全体の進捗・リソース管理とは規模が異なる。
- ◎ フルスタックWeb開発: バックエンドを主軸にフロントエンドも含むWeb開発経験が長い。
- ○ PHP / Go開発・レビュー: PHP開発経験は十分。コード・設計レビュー経験もあるが、PHP案件でのレビュー経験として明記された実績は限定的。
- ◎ SQLパフォーマンスチューニング: パチンコ業界向けDX案件で実務経験あり。
- ◎ Gitチーム開発: 長期の実務経験あり。
- ○ AWS: AWS環境へのリリース、運用に関わる実務経験あり。AWS専任インフラ要員ほどの深さではない。
- ○ TypeScript: 直近案件で実務経験あり。
- ◎ Terraform: 直近案件でGoogle Cloud環境をTerraformにより管理。

技術要件との相性はかなり良いが、案件の中心業務である3チーム横断のPM・リソース管理は経験差が大きい。技術寄りPMとして見てもらえるなら候補になるが、純PMとしての即戦力を強く求められる場合はリスクがある。
