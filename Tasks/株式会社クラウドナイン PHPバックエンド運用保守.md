# PHPバックエンド運用保守

## 概要

エンタメ企業向けのバックエンド運用保守。PHP / Laravelで構築されたサイトの改修を担当する。案件にはアダルトコンテンツを含む。

## 主な業務

- Laravelで構築された既存サイトの改修
- 不明確な仕様や挙動の調査
- 不具合原因の特定と改修
- テスト、継続的な改善

## 開発環境

- PHP
- JavaScript
- Laravel
- Docker
- CircleCI
- Jenkins
- Redmine
- JIRA

## 必須経験

- PHP(Laravel)を用いたサーバーサイド開発改修経験
- 不明確な仕様や挙動の調査や原因特定経験
- テスト駆動開発(PHPUnit等)の経験
- チーム開発やチケット管理ツールの利用経験
- DockerやDDDおよびCI/CDツールを用いた開発運用経験
- JavaScriptを用いた実務経験
- Dockerの実務経験
- CI/CDツールを用いた開発運用経験

## 歓迎経験

- 要件や目的が未確定な状態からの調査整理経験
- 不具合の恒久対応、再発防止を意識した改修経験
- 技術的負債や運用課題に対する改善提案経験
- パフォーマンスチューニング経験

### 強く合う

- 既存コード調査、原因特定、リファクタリング、改善の経験が非常に近い。
- DDD、CI/CD、JavaScript、チケット管理は実務根拠が明確。

### 注意

- Dockerの実務経験を経歴書から確認できない。
- PHPUnitを使ったTDDの実務経験も確認できない。
- 必須条件に同じDocker要件が重ねて書かれており、募集側がDocker経験を強く見る可能性がある。

### 判断
