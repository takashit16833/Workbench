- ◎ CI/CDパイプライン: GitHub Actionsを利用した自動テスト・デプロイ・DBマイグレーションのパイプライン構築経験がある。
- ○ AWSサービス基盤: AWS / Azure上のVMへのリリース経験がある。直近ではGoogle CloudをTerraformで構築・運用フローまで整備しており、クラウド基盤設計の近い実務経験もある。ただしAWS基盤を主担当として設計・維持した深い経験までは確認できない。

### 強み
- Pythonの実務経験があり、API・バックエンド開発は明確に適合する。
- 要件整理、基本設計、実装、テスト、リリース、運用保守まで一貫して対応してきたため、サービス設計・仕様整理との相性が良い。
