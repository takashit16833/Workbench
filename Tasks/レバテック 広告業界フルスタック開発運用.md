- 購入・抽選・開封演出関連の機能開発、改善
- 決済、コイン台帳の整合性・冪等性担保
- クライアント / Web連携、配信パイプライン整備
- 同時接続1,000人規模を想定した性能改善、インフラ設定見直し

## 開発環境

- React / Next.js
- AWS
- Unity

- RDB設計、SQL実務
- 金銭に直結する機能の開発・運用
- 本番サービスの障害対応を含む運用
- 生成AIを活用した開発

## 歓迎経験
