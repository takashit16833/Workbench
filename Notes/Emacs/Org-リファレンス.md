# Org リファレンス

Org mode を使うときに、操作や機能をすぐ確認するためのリファレンス。

```toc
minLevel: 2
maxLevel: 3
```

## Org バッファ

### キーバインド一覧

| キー | 操作 |
|---|---|
| `TAB` | 見出しの折りたたみ状態を切り替える |
| `S-TAB` | バッファ全体の見出し表示を切り替える |
| `M-RET` | 現在の位置に見出し／リスト項目を追加する |
| `M-S-RET` | TODO 見出しを追加する |
| `M-s-<return>` | 現在の見出しに子 TODO を追加する（独自設定） |
| `M-←` / `M-→` | 見出しやリスト項目の階層を上げる／下げる |
| `M-↑` / `M-↓` | 見出しやリスト項目を前後へ移動する |
| `C-c C-t` | TODO 状態を切り替える |
| `C-c C-q` | タグを設定・変更する |
| `C-c ,` | 優先度 `[#A]` などを設定・変更する |
| `C-c C-w` | 見出しを別の見出し・ファイルへ移動する（refile） |
| `C-c .` | アクティブな日時 `<...>` を挿入する |
| `C-c !` | 非アクティブな日時 `[...]` を挿入する。CREATED の日時などに使う |
| `C-c C-s` | `SCHEDULED` を設定・変更する |
| `C-c C-d` | `DEADLINE` を設定・変更する |
| `C-c C-c` | カーソル位置の要素に応じた処理を実行する。チェックボックスやタグなどで使う |
| `C-c C-o` | カーソル位置のリンクを開く |
| `C-c C-x C-b` | チェックボックスの状態を切り替える |

## Agenda ビュー

### キーバインド一覧

| キー | 操作 |
|---|---|
| `RET` | 元の Org 項目へ移動する |
| `TAB` | 元の Org 項目を別ウィンドウで表示する |
| `F` | Follow mode。Agenda 内でカーソルを動かすだけで元項目を別ウィンドウに表示する |
| `d` | 1日表示 |
| `w` | 1週間表示 |
| `f` | 次の日／次の週へ移動する |
| `b` | 前の日／前の週へ移動する |
| `.` | 今日へ戻る |
| `j` | 日付を指定して移動する |
| `r` / `g` | Agenda を再生成して最新状態にする |
| `t` | カーソル位置の TODO 状態を変更する |
| `C-c C-s` | `SCHEDULED` を設定・変更する |
| `C-c C-d` | `DEADLINE` を設定・変更する |
| `S-→` / `S-←` | 日付を1日ずつ後ろ／前へずらす |
| `:` | タグを変更する |
| `,` | 優先度 `[#A]` などを変更する |
| `+` / `-` | 優先度を上げる／下げる |
| `e` | 作業量 `EFFORT` を設定する |
| `z` | その項目にメモを追加する |
| `l` | Logbook を表示する。DONE になった項目や作業記録を見る |
| `E` | 元項目の本文も Agenda 内に表示する |
| `G` | 時刻グリッドの ON / OFF を切り替える |
| `s` | 開いている Org ファイルをまとめて保存する |
| `C-c C-w` | 項目を別の見出し・ファイルへ移動する |
| `$` | 項目をアーカイブする |
| `m` | 項目を一括操作対象として選択する |
| `u` | 選択を解除する |
| `B` | 選択した複数項目を一括操作する |
