## Agenda ビュー

### キーバインド一覧

| キー | 操作 |
|---|---|
| `RET` | 元の Org 項目へ移動する |
| `TAB` | 元の Org 項目を別ウィンドウで表示する |
| `F` | Follow mode。Agenda 内でカーソルを動かすだけで元項目を別ウィンドウに表示する |
| `d` | 1日表示 |
| `w` | 1週間表示 |
| `f` | 次の日／次の週へ移動する |
| `b` | 前の日／前の週へ移動する |
| `.` | 今日へ戻る |
| `j` | 日付を指定して移動する |
| `r` / `g` | Agenda を再生成して最新状態にする |
| `t` | カーソル位置の TODO 状態を変更する |
| `C-c C-s` | `SCHEDULED` を設定・変更する |
| `C-c C-d` | `DEADLINE` を設定・変更する |
| `S-→` / `S-←` | 日付を1日ずつ後ろ／前へずらす |
| `:` | タグを変更する |
| `,` | 優先度 `[#A]` などを変更する |
| `+` / `-` | 優先度を上げる／下げる |
| `e` | 作業量 `EFFORT` を設定する |
| `z` | その項目にメモを追加する |
| `l` | Logbook を表示する。DONE になった項目や作業記録を見る |
| `E` | 元項目の本文も Agenda 内に表示する |
| `G` | 時刻グリッドの ON / OFF を切り替える |
| `s` | 開いている Org ファイルをまとめて保存する |
| `C-c C-w` | 項目を別の見出し・ファイルへ移動する |
| `$` | 項目をアーカイブする |
| `m` | 項目を一括操作対象として選択する |
| `u` | 選択を解除する |
| `B` | 選択した複数項目を一括操作する |
