# AI Engineering Lab — AI共有メモリ

このディレクトリは、AI Engineering Labに参加するAIエージェント同士の引き継ぎ用ノート。ユーザー向け技術ノートではない。

## 用途と権限

- **このディレクトリ以下**：必要に応じてAIが自発的に作成・更新・整理・commit・pushしてよい。都度の許可は不要。
- `Notes/Zettelkasten/`：ユーザーが自分の言葉で書く領域。**完全に読み取り専用**。レビューとリンク候補の提案は可能。
- その他のリポジトリやファイル：このディレクトリへの書き込み許可を拡大解釈しない。プロジェクト指示や依頼に従う。

## セッション開始時

1. `learner.md` と作業に関連する `projects/` のノートを読む。
2. 記述の日時・根拠・未確認事項を確認する。
3. 既存コードを扱う場合は、そのリポジトリの最新 `main`、ユーザーが示した未プッシュ変更、実行結果を確認する。共有メモリを最新コードの代わりにしない。
4. 既知の概念を毎回ゼロから教え直さない。一方、「以前説明した」だけで理解済みとみなさない。

## 更新するタイミング

- 学習テーマ、到達点、技術選択、ユーザーの明確な理解・誤解・疑問点が変化したとき
- 再現可能な実験結果や、再利用価値のある調査・設計判断が得られたとき
- 次のAIが同じ調査や説明を不要に繰り返しそうなとき

些細な会話ごとに更新する必要はない。記録するなら実際にGitHubへ書き込み、成功を確認すること。非同期・自動実行や他のAIによる閲覧を保証しない。

## 書き方

- 原則、短く検索しやすいMarkdown。人間用の美しいノートより、次のAIが迅速に正しく状況を把握できることを優先する。
- **事実／ユーザーの発言／AIの仮説・推奨／未確認**を区別する。
- 理解度は「説明済み」「実行経験あり」「自身で説明できた」「未確認」のように、根拠となる行動と紐付けて記す。
- 日付と必要ならGitHubのcommit SHA、ファイルパスを記す。古い状態は更新・整理し、確定していない理解度を断定しない。
- 学習に無関係な私生活情報、センシティブな情報、認証情報、秘密は記録しない。
- AIの意見が過去の記録と矛盾したら、日付・根拠を確認して更新する。過去の結論を無批判に継承しない。

## ファイル

- `learner.md` — 学習目標、進め方の好み、観察に基づく理解状況
- `projects/` — 個別の学習プロジェクトについて、事実と現在地、調査結果を必要な範囲だけ記録
