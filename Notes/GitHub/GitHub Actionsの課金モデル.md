# GitHub Actionsの課金モデル

| 対象 | 料金 |
|---|---|
| 公開リポジトリの標準GitHubホストランナー | 無料 |
| 非公開リポジトリの標準GitHubホストランナー | プランごとの無料枠があり、超過分は従量課金 |
| 大規模ランナー（Larger runners） | 公開・非公開を問わず有料 |

実行時間はランナーの種類に応じた分単位の料金で計算する。成果物などの保存容量にも無料枠がある。

[公式：GitHub Actionsの課金](https://docs.github.com/ja/billing/concepts/product-billing/github-actions)
