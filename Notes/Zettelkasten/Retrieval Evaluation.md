# Retrieval Evaluation
あらかじめ定義した正解チャンクと実際の検索結果を比較し、検索性能を数値で評価する仕組み。
## 指標
- `Hit@K`
	- 上位`K`件に正解が1件以上あるか。
- `Recall@K`
	- 上位`K`件で正解チャンク全体の何割を取得できたか。
- `Reciprocal Rank(RR@K)`
	- 最初の正解が何位だったか。
	- 複数の質問で平均したものが`MRR(Mean Reciprocal Rank)`。
## 例えば
正解チャンクが`A`と`C`で、検索結果が以下だった場合。

|順位|チャンク|正解？|
|-|-|-|
| 1   | チャンクB | 不正解    |
| **2**   | **チャンクA** | **正解** |
| 3   | チャンクD | 不正解    |
| **4**   | **チャンクC** | **正解** |

**`K=2`とした場合**
- `Hit@2 = 1` : 上位２件にAがある。
- `Recall@2 = 0.5` : 正解A・Cのうち１件だけ取得。
- `RR@2 = 0.5` : 最初の正解Aが2位なので`1 / 2`。
