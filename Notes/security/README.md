# 情報処理安全確保支援士（SC）学習

## 目標

- **2027年3月の情報処理安全確保支援士試験（SC）に合格する。**
- 最も重視するのは、資料を見ずに**自分の言葉で説明できること**。
- 理解する → 説明する → 具体的な状況で判断する → 忘れないように復習する。
- 英語で読むことは副次的な目的。問題・回答・採点・Ankiは日本語で扱う。

## 教材

- 主教材：Jason Andress, *Foundations of Cybersecurity, 2nd Edition*
- 試験対策：IPA公式シラバス、公式過去問題・解答例
- 主教材のPDFはChatGPTプロジェクト等で参照し、**Gitには保存しない**。

## 学習の流れ

1. 英語のPDFを1章読む。読書中のノートや要約作成は必須にしない。
2. 読了を伝えたら、AIが本文を確認して**日本語の記述式問題を標準10問**作り、`chapterNN/quiz.md` に保存する。解答は先に表示しない。
3. VS Codeで資料を見ずに、自分の言葉で回答する。
4. AIが1問ずつ **0〜2点**（10問なら20点満点）で採点し、正しい点・不足点・模範解答を記録する。
5. 重要な誤解や不足だけ再確認する。初回80%以上かつ重大な誤解が解消していれば章の完了目安とする。
6. 定着が必要な知識だけ、原則**0〜8枚**の日本語Ankiカードにする（必要な場合のみ）。
7. `progress.md` を更新する。書籍の読了を待たず、IPAの過去問にも並行して取り組む。

## ファイルの役割

```text
progress.md          # 進捗・成績・苦手分野・次の作業
chapter01/
  quiz.md             # 問題・自分の回答・採点結果
  anki.csv            # 必要な章だけ作る
chapter02/
  ...
```

章別のフォルダは必要になったときに作る。要約ファイルは原則作らない。

`anki.csv` は **UTF-8 / ヘッダーなし / カンマ区切り / 3列（質問、回答、タグ）**。タグの例は `SC::Ch01`。

## AIと一緒に作業する場合

- 最初に `progress.md` と対象章の `quiz.md` を確認し、既存の回答・採点履歴を消さない。
- 該当するPDF本文を確認してから出題・採点する。書籍の説明と現行の推奨事項・IPAの日本語用語が違う場合は区別する。
- 不明な進捗や未採点の結果を推測で埋めない。
- 重要なのは教材作成ではなく**実際に問題を解く時間**。不要なファイルや自動化は追加しない。
- 学習記録の更新時はコミット・プッシュして引き継げる状態にする。
- 個人情報、勤務先の機密情報、著作権のある教材の全文をコミットしない。
