# lem-project-workspace 開発手順

## Lem での動作確認

Lem 自身と同じ Common Lisp プロセス上で確認する。

### REPL を開く

Lem で次を実行する。

```text
M-x start-lisp-repl
```

`M-x` は `Alt+x`。

### 初回ロード

REPL で `.asd` の場所を ASDF に登録する。

```lisp
(asdf:load-asd #P"/Users/suzukitakashi/lem-project-workspace/lem-project-workspace.asd")
```

続けてシステムをロードする。

```lisp
(asdf:load-system "lem-project-workspace")
```

ロード確認:

```lisp
(find-package :lem-project-workspace)
```

`#<PACKAGE "LEM-PROJECT-WORKSPACE">` のような値が返れば成功。

### 実装変更後の再ロード

ファイルを変更した後は、REPL で強制的に再ロードする。

```lisp
(asdf:load-system "lem-project-workspace" :force t)
```

必要に応じて開発対象の package に移動する。

```lisp
(in-package :lem-project-workspace)
```

プロンプトが `LEM-PROJECT-WORKSPACE>` のように変われば、その package 上で式を評価できる。

## 補足

`start-lisp-repl` で開く REPL は Lem 本体と同じプロセスで動作する。
そのため、Lem 自身の拡張を開発・確認するときに利用する。
