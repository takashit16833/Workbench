# Common Lisp リファレンス

Common Lisp のソースリーディングや実装中に、コードへ現れた名前を直接引くためのリファレンス。

## Common Lisp シンボル

名前順に並べる。関数だけでなく、マクロ、特殊形式、LOOP の句など、コード中で意味を確認したくなるものを同じ一覧から探せるようにする。

| 名前 | 種類 | 概要 |
| --- | --- | --- |
| `1+` | 関数 | 数値に 1 を足す。 |
| `1-` | 関数 | 数値から 1 を引く。 |
| `<=` | 関数 | 小なりイコール。複数の値を連続して比較できる。 |
| `and` | マクロ | 左から評価し、すべて真なら最後の値を返す。 |
| `case` | マクロ | 値に応じて分岐する。 |
| `char` | 関数 | 文字列の指定位置の文字を取得する。 |
| `code-char` | 関数 | 文字コードから文字へ変換する。 |
| `coerce` | 関数 | 値を指定した型へ変換する。 |
| `defconstant` | マクロ | 定数を定義する。 |
| `defpackage` | マクロ | パッケージを定義する。 |
| `defun` | マクロ | 関数を定義する。 |
| `do` | LOOP 句 | `loop` の各繰り返しで処理を実行する。 |
| `find-package` | 関数 | 名前から既存のパッケージを探して返す。見つからなければ `nil` を返す。 |
| `force-output` | 関数 | バッファ中の出力をすぐに stream へ送る。 |
| `format` | 関数 | 指定した stream へ、書式文字列に従って値を出力する。 |
| `funcall` | 関数 | 関数オブジェクトを呼び出す。 |
| `if` | 特殊形式 | 真の場合と偽の場合に分岐する。 |
| `in-package` | マクロ | 以降のコードをどのパッケージで読むか指定する。 |
| `integerp` | 関数 | 値が整数なら真を返す。 |
| `length` | 関数 | シーケンスの長さを返す。 |
| `let` | 特殊形式 | ローカル変数を定義する。各初期値は互いを参照しない。 |
| `let*` | 特殊形式 | 上から順にローカル変数を定義する。後ろの初期値から前の変数を参照できる。 |
| `list` | 関数 | リストを作る。 |
| `logbitp` | 関数 | 整数の指定 bit が 1 なら真を返す。 |
| `loop` | マクロ | 繰り返し処理を記述する。 |
| `mapcar` | 関数 | リストの各要素へ関数を適用し、結果のリストを返す。 |
| `max` | 関数 | 引数の最大値を返す。 |
| `nil` | 定数 / 偽値 | 空リストを表し、真偽値としては偽を表す。 |
| `nreverse` | 関数 | シーケンスを破壊的に逆順にする。 |
| `or` | マクロ | 左から評価し、最初に真になった値を返す。 |
| `otherwise` | CASE 句 | `case` のどの候補にも一致しなかった場合を表す。 |
| `parse-integer` | 関数 | 文字列を整数として読む。 |
| `plusp` | 関数 | 数値が正なら真を返す。 |
| `position` | 関数 | シーケンス内で値が現れる位置を探す。 |
| `push` | マクロ | 値をリストの先頭へ追加する。 |
| `return-from` | 特殊形式 | 指定した名前のブロックから即座に値を返す。 |
| `setf` | マクロ | 値を設定する汎用的な代入構文。 |
| `string` | 関数 | 値を文字列へ変換する。 |
| `subseq` | 関数 | シーケンスの一部分を取り出す。 |
| `until` | LOOP 句 | 条件が真になるまで `loop` を繰り返す。 |
| `when` | マクロ | 条件が真のときだけ本文を実行する。 |

### 補足

`defun` は関数名と同名のブロックを暗黙に作るため、関数内から `return-from` でその名前を指定できる。

~~~lisp
(defun find-value ()
  (when (found-p)
    (return-from find-value 42))
  nil)
~~~

`parse-integer` の主なキーワード引数:

| 名前 | 概要 |
| --- | --- |
| `:junk-allowed t` | 数字以外が続いていても、読めた整数部分を返す。 |
| `:start` | 読み始める位置を指定する。 |

~~~lisp
(parse-integer "115;9"
               :junk-allowed t)
;; => 115
~~~

`format` の主な制御指定:

| 名前 | 概要 |
| --- | --- |
| `~C` | 次の引数を文字として出力する。 |
| `~D` | 次の引数を10進整数として出力する。 |

## リーダー記法・名前の慣習

| 記法 | 概要 |
| --- | --- |
| `#'foo` | 関数 `foo` の関数オブジェクトを取得する。 |
| `#\\A` | 文字リテラル。 |
| `#x40` | 16進数リテラル。 |
| `'foo` | `foo` を評価せず、そのまま値として扱う。 |
| `+name+` | 定数名によく使われる命名慣習。 |
| `:foo` | キーワードシンボル。`KEYWORD` パッケージに属し、自分自身を値として持つ。 |
| `package:symbol` | パッケージから export されたシンボルを参照する。 |
| docstring | `defun` や `defconstant` などの定義に付ける説明文字列。 |

~~~lisp
:foo
#\A
#x40
'string
#'code-char
my-package:enable
~~~

## ASDF

ASDF は Common Lisp のシステム定義・読み込みを行う仕組み。
Common Lisp 標準そのものではないが、ライブラリやアプリケーションの構成管理で広く使われる。

| 名前 | 概要 |
| --- | --- |
| `asdf:load-system` | 指定した ASDF system と、その依存先を読み込む。 |
| `defsystem` | ASDF system を定義する。 |
| `:components` | system を構成するファイルやディレクトリを指定する。 |
| `:depends-on` | 先に読み込む必要がある別の ASDF system を指定する。 |
| `:file` | 読み込む Common Lisp ソースファイルを指定する。拡張子 `.lisp` は通常省略する。 |
| `:module` | 複数の構成要素をまとめるディレクトリ単位の構成を表す。 |
| `:serial t` | `:components` の構成要素に、直前の構成要素への依存関係を順番に設定する。 |

~~~lisp
(defsystem "my-system"
  :depends-on ("some-library")
  :serial t
  :components
  ((:module "src"
    :components
    ((:file "package")
     (:file "main")))))
~~~

~~~lisp
(asdf:load-system "my-system")
~~~
